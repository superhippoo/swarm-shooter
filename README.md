# SWARM//ZERO

> **현재 상태**: 이 브랜치는 사용자가 승인한 **10단계 캠페인**을 통합하는 중입니다. 현재 커밋은 그대로 실행 가능한 완성본이 아니며 `npx tsc --noEmit`이 실패할 수 있습니다. 남은 작업과 정확한 상태는 [`docs/campaign-handoff.md`](docs/campaign-handoff.md)를 먼저 읽으세요.

독창적인 SVG와 합성 사운드로 만든 데스크톱·모바일 탑다운 웹 호드 슈터입니다. TypeScript, Vite, Phaser 3를 사용하며 싱글 플레이어 10단계 작전으로 확장 중입니다.

## 실행

```sh
npm ci
npm run dev
```

- 게임: http://127.0.0.1:5173/
- 개발 대시보드: http://127.0.0.1:5173/dashboard.html
- 상태 API: http://127.0.0.1:5173/api/status

프로덕션 미리보기:

```sh
npm run build
npm run preview
```

미리보기는 기본적으로 `http://127.0.0.1:4173/`입니다.

## 게임 방법

`scout`는 빠른 이동과 재장전, `heavy`는 높은 생명력과 예비 탄약이 특징입니다. 중계기에 침투하고, 반경 300px 구역에서 신호를 25초 동안 방어한 뒤 북서 승강기로 탈출하면 승리합니다. 생명력이 0이 되면 실패하며 같은 캐릭터로 재시작할 수 있습니다.

### 데스크톱

- `WASD`: 이동
- 마우스: 조준
- 마우스 왼쪽 버튼: 사격
- `1`, `2`, `3` 또는 마우스 휠: 무기 교체
- `R`: 재장전
- `Esc`: 일시정지·재개
- 일시정지의 `화면 진동` 체크박스: 진동 켜기·끄기

### 모바일 가로 화면

- 게임 캔버스와 침머라가 브라우저의 가로 화면 전체를 채우며, 기기 비율에 따라 보이는 전장 범위가 조정됩니다.
- 왼쪽 이동 스틱: 방향과 기울기로 이동
- 자동 조준: 화면에 보이는 활성 적 중 장애물에 가려지지 않은 가장 가까운 적 추적
- `FIRE`: 소총은 누르는 동안 연사, 산탄총·발사기는 새 탭마다 한 발
- `재장전` 버튼과 하단 무기 버튼: 재장전·무기 교체. 이동 스틱을 유지한 채 다른 손가락으로 누를 수 있습니다.
- 오른쪽 위 `Ⅱ`: 일시정지·재개
- 세로로 전환하면 전투가 일시정지되며, 가로로 돌아온 뒤 재개 버튼을 누릅니다.

무기는 자동 소총 `RS-7`, 8펠릿 산탄총 `SG-4`, 범위 폭발 무기 `GL-2`입니다. 산탄총과 폭발 무기는 새 클릭·탭마다 한 번 발사합니다. 보급 상자는 생명력과 예비 탄약을 회복하며, 세 무기가 모두 소진돼도 비상 소총 탄약을 제공합니다.

## 그래픽과 에셋

맵은 의료 구역·정화 구역·중계기·승강기로 구분된 산업 시설이며, 금속 패널·침대·콘솔·벽·배관·환기구에 상면과 측면 명암을 적용했습니다. 캐릭터는 하체 보행, 상체 조준, 무기별 외형과 반동으로 구성하고 적도 종별 2프레임 보행을 사용합니다. 실시간 조명 대신 스프라이트 명암과 정적 맵 레이어를 사용하며, 기존 충돌 범위와 전투 규칙은 바꾸지 않습니다.

`public/assets/`의 환경·캐릭터·무기·적·초상화는 외부 에셋 없이 제작한 SVG입니다. 제작 원본에서 28개 파일을 다시 만들려면 다음을 실행합니다. 조준선까지 합치면 게임의 독창적 SVG는 29종입니다.

```sh
npm run art:generate
```

생성기를 실행하면 같은 경로의 수동 SVG 수정도 덮어쓰므로, 에셋 변경은 `scripts/generate-art.mjs`에 반영합니다. 에셋 URL은 Vite의 base 경로를 따르고 로드 실패 시 생성 텍스처로 대체합니다.

## 검증

```sh
npm run verify
npm run test:e2e
```

`verify`는 상태 파일 검증, Vitest, TypeScript 검사, 프로덕션 빌드를 실행합니다. 브라우저 테스트를 처음 실행하기 전에는 Chromium을 설치하세요.

```sh
npm run browser:install
```

브라우저 테스트는 실제 키보드·마우스와 모바일 터치 입력으로 다음을 확인합니다.

- 데스크톱 두 캐릭터와 모바일 한 캐릭터의 침투·방어·탈출 완주와 승리 후 재시작
- 무기별 발사·재장전·반자동·폭발 피해
- 모바일 멀티터치 이동·자동 조준 사격, 취소·회전 시 입력 해제와 가로 화면 배치
- 사망·재시작·일시정지·화면 진동 설정
- 자연 웨이브 50기 이상의 객체 상한과 게임 난부 시간 기반 FPS 표본
- 캐릭터 보행·무기별 외형·총구 위치와 선택 초상화
- 대시보드·상태 API·SVG 29종 제공과 로드 실패 시 생성 텍스처 대체

기본 포트는 5173이며 필요하면 `SWARM_DEV_PORT` 또는 `SWARM_BASE_URL`로 변경할 수 있습니다.

Linux에 Chromium 실행 라이브러리가 없다면 Playwright의 `install-deps` 안내가 필요할 수 있습니다. Windows npm에서 `browser:install`의 환경 변수 문법이 해석되지 않으면 Git Bash에서 `export PLAYWRIGHT_BROWSERS_PATH=0 && npx playwright install chromium`을 실행합니다. 이 저장소의 테스트 실행기는 `artifacts/browser-libs`와 `artifacts/fontconfig.xml`이 있으면 시스템 설치 없이 로컬 라이브러리·한글 글꼴을 사용합니다. `artifacts/`의 캡처, 성능 결과, 임시 복사본은 Git에 커밋하지 않습니다.

## 구현 범위

- 캐릭터 2종, 무기 3종, 적 3종, 3단계 임무 1개
- 모바일 가로 컨트롤, 자동 조준, 터치 사격·재장전·무기·일시정지 버튼
- 최대 적 72, 발사체 192, 입자 384, 잔해 40, 오디오 12 voice
- 객체 풀과 128px 공간 해시, 화면 밖 렌더링 제한
- `project-status.json`을 단일 원천으로 하는 3초 자동 갱신 대시보드
- 온라인·로그인·결제·외부 DB·추가 맵·육성·상점은 제외

성능 목표는 데스크톱 하드웨어 가속 브라우저에서 60fps에 가까운 동작입니다. headless SwiftShader는 소프트웨어 WebGL이므로 이보다 느리며, 실제 측정 환경과 결과는 `artifacts/stress-result.json`에 기록합니다. 실제 모바일 하드웨어의 FPS와 청감 사격감·사운드는 자동 테스트로 판정하지 않으므로 실기기에서 확인해야 합니다.
