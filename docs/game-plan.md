# SWARM//ZERO — 10단계 캠페인 계획

이 문서는 승인된 구현 계약이며 완료 보고가 아니다. 현재 구현·검증 상태는 `project-status.json`의 캠페인 작업과 사용자 요청 이력을 기준으로 한다. 실제 수치는 [balance.md](./balance.md)와 캠페인 데이터를 따른다.

## 1. 범위와 플레이 뼈대

- 데스크톱과 모바일 가로 브라우저용 싱글 플레이어 10단계 캠페인 **BLACK DEW / 검은 이슬**이다.
- scout/heavy 중 하나를 선택하고 기본 rifle/shotgun/launcher로 시작한다. 클리어 보상으로 ARC-5·Rail Lance·Flame Projector·MX-8 Mine Layer를 그 판 동안 해금한다.
- 목표 시간은 약 18~22분이다. 적 HP를 무한히 올리기보다 유한 웨이브의 수·구성·방향·출현 간격과 목표 압박으로 난이도를 높인다.
- 기존 캐릭터, 기본 무기, 데스크톱 조준·사격, 모바일 자동 조준·멀티터치·전체 화면, 독창적 SVG·Web Audio를 유지한다.
- 영구 계정 육성, 상점, 로그인, 온라인, 외부 게임 에셋과 3D 엔진은 제외한다.

## 2. 화면과 진행 규칙

`GameScreen`은 `menu / stageIntro / playing / paused / stageClear / victory / dead`를 사용한다. `CampaignSnapshot.phase`는 `intro / combat / clear / complete`다.

- **STAGE XX START**: 단계 제목과 목표를 1.2초 표시한 뒤 전투를 시작한다. 소개 시간에는 스폰·재장전·전투·목표 시계가 진행하지 않는다.
- **STAGE XX CLEAR**: 전투를 정지하고 단계 시간·처치·HP·무기 보상을 표시한다. 실제 `NEXT STAGE` 입력으로 다음 단계로 이동한다.
- 10단계도 먼저 `STAGE 10 CLEAR`를 표시하고, 결과 확인 입력 후 최종 **MISSION COMPLETE**로 이동한다. 캐릭터·총 시간·총 처치를 표시한다.
- 죽으면 현재 단계부터 다시 시작한다. 단계 진입 때의 해금·통계 체크포인트로 복원하고 HP와 탄약을 채운다.
- 단계 전환은 `runId`를 바꾸지 않고, 현재 단계 재시작은 증가시킨다. 새 캠페인과 메뉴 복귀는 해금과 통계를 초기화한다.
- 각 단계 시작 시 HP와 해금된 모든 무기의 탄창·예비 탄약을 채운다. 일시정지·화면 회전·숨김에서는 전투와 소개 시계를 포함한 진행이 멈추고 입력을 해제한다.

## 3. 시설과 목표 데이터

같은 2400×1600 세계에서 `medbay / reactor / hive` 세 레이아웃을 사용한다. 기존 환경 SVG를 재사용하되 장애물·데칼·색조·시작점·목표 좌표를 데이터로 지정한다. 10개의 별도 대형 맵 원화는 만들지 않는다.

`StageDefinition`은 `id / title / layoutId / playerStart / maxAlive / objectives / waves / supplies / unlock`을 가진다. 모든 물리·자동 조준·목표·방어·보급 계산은 현재 스테이지 레이아웃을 사용하며, 진행 중 전역 설정을 변경하지 않는다.

목표는 정의된 순서대로 진행한다.

- `reach`: 목표 좌표와 반경 안에 도달한다.
- `defend`: 지정 구역 안에서만 누적 시간을 진행한다. 밖에서는 방어 시간과 그 목표의 스폰 시계가 멈춘다.
- `collect`: 고정된 냉각 셀·퓨즈를 실제로 접근해 회수한다.
- `purge`: 해당 목표가 소유한 유한 스폰이 모두 생성되고 전멸해야 한다. 다른 목표의 적이나 미래 소환으로 대신 채우지 않는다.
- `hunt`: 표시된 elite/alpha Brute를 지정 수만큼 처치한다.
- `extract`: 마지막 목표 좌표 반경 안에 도달해 단계를 마친다.

`CampaignWaveDefinition`은 목표 ID, 발동 시각, 적 수, 방향, elite/alpha 수와 필수 여부를 가진다. 필수 스폰은 큐가 차도 버리지 않고 남은 풀 공간에 순차 방출한다.

## 5. 난이도와 보스

- 단계별 HP 배율은 최대 1.36, 속도는 약 1.11, 접촉 피해는 최대 1.36으로 제한한다.
- 출현 간격은 100ms에서 65ms로 점진적으로 좁아진다. 출현 예고 300ms와 피격 무적 1000ms는 유지한다.
- 엘리트는 표시된 Brute 강화 변형이다. Alpha는 약 1800 HP와 75/50/25% HP의 한 번씩의 소환을 사용한다.
- 보스 소환도 해당 단계의 유한 스폰에 포함한다. 무한 반복 소환으로 클리어를 막지 않는다.

## 6. 무기 해금과 입력

모든 무기는 캐릭터의 재장전·예비 탄약 배율을 따른다. 새 무기는 다음 단계에서 사용할 수 있고, 기존 무기도 선택할 수 있다.

- **ARC-5**: 반자동 연쇄 전격. 최대 5개 대상을 시야가 닿는 범위에서 한 번씩 타격한다.
- **Rail Lance**: 반자동 관통 사격. 충돌 순서대로 최대 8명을 타격하고 첫 장애물에서 멈춘다.
- **Flame Projector**: 유지 발사. 원뿔 안의 적을 공간 해시와 시야 검사로 주기적 타격한다.
- **MX-8**: 반자동 지뢰 설치. armed 후 접근한 적을 폭발시키며 최대 8개를 유지한다.

데스크톱은 WASD·마우스 조준/사격·R 재장전·Esc·`1~7`·휠을 사용한다. 모바일은 왼쪽 스틱 이동, 자동 조준, FIRE, 재장전과 48px 이상의 이전/다음 무기 버튼을 사용한다. 이동·사격·재장전·무기 순환은 독립 터치 포인터로 처리한다.

## 7. 보급과 소프트락 방지

- 각 단계 두 개의 고정 보급은 현재 보급 규칙을 따라 HP와 해금된 무기 예비 탄약을 회복한다.
- 해금된 모든 무기의 `Σ(magazine + reserve)`가 0인 상태가 1500ms 지속되면 기존 쿨다운 6000ms를 확인하고 `rifle.reserve += 24`를 적용한다.
- 비상 탄약은 HP를 회복하지 않는다. 사망할 수는 있지만 모든 탄약이 없어 영구히 진행할 수 없는 상태는 만들지 않는다.

## 8. 연출과 성능 예산

- 관통·연쇄·원뿔·폭발은 실제 피해를 계산하고, 발사 한 번에 하나의 소리·반동 이벤트를 사용한다.
- 발사/폭발당 5·10·20 다중 처치 구간에 짧은 콜아웃을 표시한다. 대상 수만큼 소리와 진동을 중첩하지 않는다.
- 장식 풀 부족은 실제 피해·해금·목표 진행에 영향을 주지 않는다.
- 적 72, 발사체 192, 입자 384, 잔해 40, 보급 8, 오디오 12, 지뢰 8, 광선/연쇄 효과 32, 목표 수집물 8을 상한으로 유지한다.
- 자동 조준 후보는 약 100ms 간격으로 계산하고 선택 대상 추적은 매 프레임 갱신한다. 공간 해시·분산 AI·정적 시설 청크·객체 풀을 유지한다.
- 저사양 모바일에서는 장식만 줄이고 적 수·피해·목표 조건은 그대로 유지한다.

## 9. 완료 검증

- 10개 정의와 목표 순서·해금·체크포인트·필수 스폰·신규 무기 규칙을 단위 테스트한다.
- 데스크톱 scout/heavy와 모바일 heavy가 실제 입력으로 모든 단계를 연속 완주하고 START/CLEAR/MISSION COMPLETE를 확인한다.
- 죽음·현재 단계 재시작, 일시정지·회전·숨김, 모바일 무기 순환과 독립 멀티터치, 740×360·780×360·844×390을 확인한다.
- 후반 대형 웨이브와 반복 전환에서 풀 상한·오디오·시설 텍스처 정리·필수 스폰 누락을 확인한다.
- 최종 표준 검증·전체 브라우저 회귀·Pages 빌드·프로덕션 경로와 공개 URL을 확인하고, 실제 모바일 하드웨어·Safari·청감은 별도 실기기 검증으로 남긴다.
